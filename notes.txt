I'm using it to create monthly reports every month to save a lot of manual effort. The SSandAL_local_run.py is the main file. alertlabapi and simplesubapi are functions for respective apis


Current set up is that I have a lambda function in aws for each property I query (8 properties). The lambdas have layers which contain pandas, numpy, requests, and also the helper modules (.py files). 
The templates for lambda functions are stored in the AWSLambdafunction dir for each scenario. There are three scenarios 1)Pull data from Simplesub only 2)Pull data from Alertlab only 3)Pull data from both of them.

Lambda is called by Zoho flow with a function url. Lambda returns a csv string that Zoho converts it in a file and sends it to my client.
